# NeoGadgets Landing Page

NeoGadgets is a simple static website written in HTML and CSS. It provides a Hebrew product showcase, links to social media channels, and legal information pages such as the privacy policy, terms of use and an accessibility statement.

## Project Structure

- `index.html` – Main landing page with featured products and a cookie consent banner.
- `accessibility.html` – Accessibility statement.
- `privacy-policy.html` – Privacy policy.
- `terms.html` – Terms of use.
- `assets/` – Images and the main stylesheet (`styles.css`).

## Usage

Open `index.html` directly in your browser or serve the project with any static server.

```bash
# Example using Python's built-in server
python -m http.server 8000
```

Then browse to `http://localhost:8000`.
